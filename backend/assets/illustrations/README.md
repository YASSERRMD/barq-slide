# Bundled Abstract SVG Illustrations

Offline fallback illustrations used when Unsplash is unavailable or an access key is not configured.

## Source
These are custom abstract geometric SVGs created for barq-slides. All are in the public domain (CC0).

## Usage
The illustration resolver maps semantic queries to the closest illustration by category.

| File | Category | Use Cases |
|------|----------|-----------|
| abstract-data.svg | Data & Analytics | Data slides, charts, statistics |
| abstract-people.svg | People & Teams | HR, team, leadership slides |
| abstract-tech.svg | Technology | Cloud, software, AI slides |
| abstract-growth.svg | Growth & Finance | Revenue, growth, trends |
| abstract-process.svg | Process & Flow | Workflow, pipeline, steps |
| abstract-globe.svg | Global & Scale | International, market, reach |
| abstract-idea.svg | Innovation & Ideas | Strategy, creativity, planning |
